## 📌 About This Challenge

This repository documents my **75 Hard DSA Challenge** — a focused journey to master **advanced Data Structures & Algorithms** by solving and explaining **only HARD problems** from **LeetCode** and **Codeforces**.

Each day includes:
- ✅ Clean, optimized solution
- ✅ Conceptual explanation
- ✅ YouTube explanation video
- ✅ Public progress tracking

This is not random grinding.  
This challenge is about **depth, consistency, and engineering-level thinking.**
